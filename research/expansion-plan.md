## 3. 管理・アーキテクトレベルのコンテンツ拡充 可否判定

### 3-1. 判定結果: **CCA-F学習サイトへの管理レベルコンテンツ追加は「限定的に実施」が妥当**

### 3-2. 判定根拠

**追加すべき理由:**

1. **D5（コンテキスト管理と信頼性・15%）の範囲内**: Rate Limits、Service Tiers、データプライバシーはD5の出題範囲に含まれる可能性が高い
2. **D1（エージェント設計・27%）の安全設計**: Secure Deploymentはエージェントアーキテクチャの一部として出題される可能性が高い
3. **シナリオ問題の文脈知識**: Enterprise機能やガバナンスはシナリオ問題の背景知識として問われる可能性がある

**追加を限定すべき理由:**

1. **CCA-Fは技術資格**: 管理・ガバナンスの体系的出題は想定されていない（試験ガイドの5ドメインに管理専用ドメインなし）
2. **Academy自体に管理コンテンツがない**: 公式の学習リソースに管理レベルが存在しないことは、CCA-F試験での出題比重が低いことを示唆
3. **Advanced Architectが上位資格**: エンタープライズガバナンスは2026年後半のAdvanced Architect資格で本格的に扱われる見込み
4. **対象ユーザーは非エンジニア**: 管理レベルの技術的内容は対象ユーザーにとって難度が高すぎる可能性

### 3-3. 追加方針

| レベル | 追加範囲 | 理由 |
|--------|---------|------|
| **追加する** | Rate Limits / Service Tiers / Guardrails / Secure Deployment / データプライバシー基礎 | CCA-F試験のD1・D5で出題される可能性が高い |
| **概要のみ追加** | Admin API / Enterprise機能 / 組織ロール | シナリオ問題の背景知識として |
| **追加しない** | SSO/SCIM実装詳細 / 監査ログ設定 / コスト最適化戦略 | CCA-F範囲外。Advanced Architect向け |

## 6. 結論

### 今回の調査で判明した最重要ポイント

1. **D5（コンテキスト管理と信頼性）のギャップが想定以上に大きい**: Rate Limits、Service Tiers、Strengthen Guardrails、データプライバシーという4つの重要領域がROADMAPから漏れていた。配点15%と最小だが、出題される知識の幅は広い。

2. **管理・アーキテクトレベルのコンテンツはCCA-F範囲内で限定追加が適切**: Academy・GitHub Coursesともに管理レベルの体系的内容は存在せず、CCA-F試験での出題比重は低い。ただしSecure Deployment（D1）とRate Limits/Guardrails（D5）は試験範囲内であり、追加すべき。

3. **上位資格（Advanced Architect）は2026年後半**: 本格的な管理・ガバナンスコンテンツはAdvanced Architect資格のリリースに合わせて対応するのが効率的。

4. **Bedrock版・Vertex AI版コースの再評価**: ROADMAP記載の「低」から「高」に格上げ。CCA-Fの全ドメインをカバーしており、AWS/GCPユーザーには有力な学習リソース。

### 推奨アクション

既存ROADMAPのPhase 1（D1・D2深化）を開始しつつ、ROADMAP.md自体の更新を先行させる。D5の強化をPhase 2に組み込み、問題集作成と並行して進める。
