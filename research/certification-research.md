# Anthropic認定資格・認定プログラム調査レポート

> 調査日: 2026-03-26

## 1. CCA-F以外の認定資格の有無

### 1-1. 現在提供中の認定資格

2026年3月時点で、Anthropicが提供する認定資格は**CCA-F（Claude Certified Architect — Foundations）のみ**。

| 項目 | 詳細 |
|------|------|
| 正式名称 | Claude Certified Architect — Foundations |
| リリース日 | 2026-03-12 |
| 問題数/時間 | 60問 / 120分 |
| 合格点 | 720/1000 |
| 受験料 | $99（先着5,000名は無料） |
| 受験資格 | Claude Partner Networkメンバー限定 |
| 位置づけ | Anthropic初の公式技術認定資格。資格体系の**エントリーポイント** |

### 1-2. 発表済みの今後の認定資格（2026年後半予定）

Anthropic公式発表（Claude Partner Network発表文）により、**2026年後半に以下3カテゴリの追加資格が計画されている**ことが確認できた。

| カテゴリ | 想定対象者 | 詳細 |
|---------|-----------|------|
| **Advanced Architect** | シニアアーキテクト | CCA-Fの上位資格。エンタープライズ規模のシステム設計、より複雑なアーキテクチャシナリオを対象 |
| **Developer** | 開発者 | システム全体の設計ではなく、Claude機能の実装レベルのスキルを検証 |
| **Seller** | 営業・プリセールス | Claude製品の販売・提案能力を検証（技術資格ではなくセールス資格） |

**重要**: 具体的な資格名称（CCA-Aなど）、試験仕様、リリース日は未発表。CCA-F保有者には新資格への**優先アクセス**が付与される予定。

### 1-3. 資格ロードマップ・体系図

公式の体系図は未公開。ただし、各種報道・分析記事を総合すると以下の構造が想定される：

## 3. 他社AI資格との比較・位置づけ

### 3-1. 主要AI認定資格の比較表

| 項目 | CCA-F (Anthropic) | AWS AI Practitioner | AWS ML Specialty | Google Cloud Professional ML Engineer | Azure AI Engineer (AI-102) |
|------|-------------------|--------------------|-----------------|------------------------------------|--------------------------|
| **レベル** | 基礎〜中級 | 入門 | 上級 | 上級 | 中級 |
| **対象者** | Claudeアーキテクト | 非技術職含む全般 | MLエンジニア（2年以上） | ML/データエンジニア | AI開発者 |
| **問題数/時間** | 60問/120分 | 85問/120分 | 65問/180分 | 50-60問/120分 | 約50問/100分 |
| **受験料** | $99（先着5,000名無料） | $100 | $300 | $200 | $165 |
| **出題形式** | シナリオベース4択 | 多肢選択+複数回答 | 多肢選択+複数回答 | 多肢選択+複数回答 | 多肢選択+複数回答 |
| **特徴** | 特定AIモデル（Claude）特化 | AWS AI/MLサービス全般 | AWS ML深掘り | GCP MLパイプライン全般 | Azure AIサービス統合 |
| **合格率（推定）** | 未公開 | 約70% | 約65% | 非公開 | 非公開 |
| **年収相場** | 未確立 | — | $175k | $160k | $165k |

### 3-2. CCA-Fの位置づけ分析

**CCA-Fのユニークな特徴：**

1. **AIモデル特化型資格の先駆け**: AWS/Google/Azureがクラウドプラットフォーム全体のAI/MLサービスを対象とするのに対し、CCA-FはClaude単体のアーキテクチャ設計に特化した**初のAIモデル専門資格**
2. **シナリオベース出題**: 全6シナリオからランダム4つが出題される実践重視の形式。他社資格のような知識確認型とは異なるアプローチ
3. **エージェント設計重視（27%）**: AIエージェントのアーキテクチャ設計という最新領域に最大配点。他社資格にこの分野の深い出題はまだない
4. **パートナーエコシステムとの連動**: 資格取得がパートナー評価に直結する設計（AWSパートナーコンピテンシーに類似）

**他社資格との補完関係：**

| 組み合わせ | メリット |
|-----------|---------|
| CCA-F + AWS AI Practitioner | Claudeの深い知識 + AWSクラウドAI全般の幅広い理解 |
| CCA-F + AWS ML Specialty | Claude設計 + ML基盤の深い技術力を証明 |
| CCA-F + Google Cloud ML Engineer | Claude設計 + GCP MLパイプラインの実装力 |
| CCA-F + Azure AI Engineer | Claude設計 + Microsoftエコシステムとの統合力 |

## 4. 管理・アーキテクトレベルの学習リソース

CCA-Fの上位資格は未リリースだが、管理・アーキテクトレベルの学習に活用できるリソースは以下の通り。

### 4-1. Anthropic公式リソース

| リソース | 内容 | アクセス |
|---------|------|---------|
| Anthropic Academy「Building with the Claude API」 | API基礎からエージェント・RAGまで包括（8時間超） | 無料 |
| Anthropic Academy「Claude Code in Action」 | Claude Codeの高度な活用（21レッスン） | 無料 |
| MCP Advanced Topics | サンプリング・通知・トランスポート機構 | 無料 |
| Agent Skills | Skills構築・配布・サブエージェント連携 | 無料 |
| 公式ドキュメント（Agent SDK） | エージェントループ・サブエージェント・コンテキスト隔離 | 無料 |
| GitHub courses（5コース） | Jupyter Notebook形式のハンズオン教材 | 無料 |

### 4-2. 外部リソース（日本語）

| リソース | 媒体 | 特徴 |
|---------|------|------|
| CCA-F試験対策ロードマップ | Note | 5ドメイン解説+無料学習リソース紹介 |
| CCA-F完全ガイド【2026年版】 | Note | 出題範囲・勉強法・取るべき人の判断基準 |
| CCA試験ガイド完全解説 | Zenn | サンプル問題含む・最も技術的に詳細 |
| CCA「AIネイティブ資格」 | Qiita | AWS認定との対比・キャリアパス分析 |

### 4-3. 上位レベル学習への推奨パス

現時点でAdvanced Architect資格が未リリースのため、管理・アーキテクトレベルの学習には以下の段階的アプローチを推奨：

```
Step 1: CCA-F取得（現在の学習サイトで対応）
    ↓
Step 2: Anthropic Academy全コース修了（特にAPI・Code・MCP・Agent Skills）
    ↓
Step 3: 公式ドキュメントのAgent SDK・MCP詳細を深掘り
    ↓
Step 4: 実プロジェクトでのClaude実装経験の蓄積
    ↓
Step 5: Advanced Architect資格リリース時に受験（2026年後半予定）
```

**補足**: 他社AI資格（特にAWS ML SpecialtyやGoogle Cloud ML Engineer）を並行取得することで、Claude以外のAI/MLの幅広い知識を補完でき、アーキテクトとしての総合力を高められる。
